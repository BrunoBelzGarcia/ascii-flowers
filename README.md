# ascii flowers

Trying to make up for the flowers you didn't get.

Open https://brunobelzgarcia.github.io/ascii-flowers/ on your phone or computer. The bouquet appears immediately. No downloads, installation, account, or setup required.

The static bouquet includes sunflowers, purple asters, red lilies, green foliage, and white baby's breath, rendered in colored ASCII on black. There is no animation, heart, personal name, or additional dedication.

Optional controls: Save image downloads a colored PNG. Copy ASCII text copies uncolored text; use a monospaced font when pasting. If clipboard access is unavailable, selected text appears for manual copying.

## Maintaining the site

The website lives in index.html, with no packages or build step. GitHub Pages serves the main branch's root folder. Commit changes to index.html to update the live website.

The visual direction was inspired by https://github.com/Isaac-opz/asciiFlowers. The drawing code and sunflower/aster artwork are independently written.
