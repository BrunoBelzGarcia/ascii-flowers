# ASCII Bouquet

A still bouquet of golden sunflowers, purple asters, red lilies, white baby's breath, and leafy stems on black. Every visible mark in the artwork is an ASCII character.

Live site: https://brunobelzgarcia.github.io/ascii-bouquet/

## Use

Open the live link on a phone or desktop. Save image downloads a colored PNG. Copy ASCII text copies uncolored characters; paste into an editor using a monospaced font. If clipboard permission is unavailable, the page shows selectable text for manual copying.

No animation, heart, dedication, personal name, accounts, trackers, or external assets. Rendering happens once at startup and again when the viewport changes.

## Run or edit

Open index.html directly in a modern browser, or serve this folder using any static server. All CSS and JavaScript are contained in index.html. No installation or build step is required.

GitHub Pages deploys the main branch's root folder. Edit index.html and commit to update the live site.

## Reference

The colored ASCII bouquet style was inspired by https://github.com/Isaac-opz/asciiFlowers. This page uses independently written drawing code and original sunflower and aster artwork.
