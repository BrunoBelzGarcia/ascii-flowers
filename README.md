# ASCII Flowers

ASCII Flowers is a little “Flowers for you” card. A wrapped bouquet blooms against a twinkling night sky. The page draws the flowers in colored ASCII characters, using the same idea as a face like `(^_^)` on a bigger canvas.

[Open the card](https://brunobelzgarcia.github.io/ascii-flowers/)

I hope you like it <3

## Using the card

- **Replay bloom** restarts the animation.
- **Copy ASCII text** copies the finished bouquet as plain text.
- **Download image** saves the fully opened bouquet as a 1280 × 1500 PNG.

## Run locally

Open `index.html` in a browser. The HTML, styles, and Canvas drawing code are all in that file. There are no dependencies to install or build steps to run. To test clipboard permissions as you would on the hosted site, serve the folder over `localhost`.
